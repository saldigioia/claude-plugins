## Verdict

The muxing has never been the problem, and it still is not: the prediction
contract, waiver binding, census logic, discontinuity budgets, probe-window
floor (bash side), array/quoting discipline, and the exit-trap machinery all
survived deliberate attack (full list at the end). What did not survive is the
same layer 1.15.2 indicted, one storey deeper: **the pipeline's evidence
collection fails open.** At at least six independent, now-measured sites, "the
probe returned nothing" is indistinguishable from "the property is absent" —
and the verdict machinery then builds a confident claim on the missing
evidence. The worst of these ships a silently audio-stripped file as
"verified lossless, exit 0." A seventh systemic gap — no writer exclusivity —
lets a second concurrent run corrupt an artifact the first run blesses.

One sentence to carry forward: **1.15.2 taught "UNPROVEN ≠ FAILED"; this
checkup adds the twin rule "EMPTY ≠ ABSENT" — no probe result may feed a
verdict without its exit status.**

## Class A — silent false-bless (wrong bytes ship under exit 0)

### A1 — the audio plan fails open: one failed probe ⇒ video-only MOV, "verified lossless", exit 0  **CONFIRMED twice, independently**
`remux.sh:135–201` — `PLAN=$(ffp -v error -select_streams a … | awk …) || true`.
A failure of that one ffprobe call (rc≠0, stderr discarded) yields `PLAN=""`,
byte-identical to a genuinely audio-free source. `mov.sh:519` takes
`MODE=none`, builds video-only; `verify.sh:407` disables gates (f)/(g) via the
same `grep -c . || true` conflation ("no audio tracks — gate N/A"); the D5
census then asserts the *poisoned plan* (`planned=1 written=1 match=ok`).
Measured end-to-end by two auditors with a PATH shim failing only that query
shape: the banner prints `audio=aac` two lines above `-- no audio (or none
kept) -> pure copy --`, and the run ends `>> DONE … verified lossless`, rc=0,
output has zero audio streams. Feeders of the same class: `mov.sh:499`
(`PLANOUT=$(bash remux.sh … || true)`), `rebuild-paff.sh:101`, and
`mov.sh:174` / `auto.sh:67` — `eval "$(probe.sh --kv | grep …)"` discards
probe.sh's exit status while probe.sh's `aud_manifest_kv` awk **fabricates
`PR_AUD_COUNT=0` from its END block even when its producer failed** (measured:
probe exits 1, 36 keys still emitted, Dolby-E refusal loop silently disabled).
This is the exact class the FLAC-5.1/MP2 track-drop incident created the
keep-all policy to prevent. Fix shape is already in-house:
`clean.sh:45–46` (`set +e; x=$(…); rc=$?; set -e; [ -n "$x" ] || refuse`) —
the defended and undefended sites differ only by author discipline.

### A2 — no writer exclusivity: a second run corrupts an artifact the first run blesses  **CONFIRMED**
`lib-mux.sh:55` (`rtm_part` — deterministic `out.part.mov`), `remux.sh:391,
396, 457, 464` (`ffmpeg -y … "$PART"` → census on `$PART` → `mv -f`). No
O_EXCL, no lockfile, anywhere. Measured: run A (298 MB) and run B started on
the same OUT; A printed `census: … plan matched … wrote: out.mov`, **rc=0**,
and the delivered file fails on first read (`Invalid NAL unit size …`). The
census and the `mv` are not atomic against a second writer, so a verdict
earned on one byte-stream blesses another. Same exposure:
`mov.sh:418` (`idrtrim.tmp`), `auto.sh:166` (`.autobest`), batch/waiver
sidecars — and a *stale* `.part` retained as FAIL evidence is silently
truncated by the next run's `-y`.

### A3 — no `LC_ALL=C`: a comma-decimal locale disarms gate (f) silently  **CONFIRMED**
No script pins LC_NUMERIC (`LC_ALL=C` appears only on `sort`/`grep` calls).
macOS awk under `de_DE.UTF-8`: input `"3.5"+1 → 4` (truncates), printf
`%.3f → "1,500"` — and those comma strings re-enter other awk program texts
and ffmpeg args. Measured: the verify.sh gate-(f) chain (`:416–418`) computes
`delta=2,543`, the follow-up `awk "BEGIN{exit !((2,543) > (0))}"` is a syntax
error, the `if` takes the else branch — **a 2.543 s A/V desync passes as
"durations consistent."** Also measured: `ts-health.sh` exits rc=2 with zero
output under the same locale. Any operator whose terminal inherits a European
system locale is running with the float gates off. Fix: one
`export LC_ALL=C` at each entry point (ffprobe itself always emits C-locale —
measured — so the corruption is purely consumer-side).

### A4 — derive-dts gates its chapter-mux hard stop on the narrow confession pattern  **CONFIRMED drift; impact version-dependent**
`lib-paff.sh:418` (`mux_confessions`, narrow: `non-?monotonic dts`) vs `:445`
(`mux_confessions_scoped`, broadened 1.14 with the bench-measured extra
spellings `non-?monoton(ic|ous)` / `non monotonically increasing`). The 1.14

invented timing**. One-line fix; confirm on a 6.1 leg with an induced
backward DTS.

## What this earns — the rules, and the next rounds

1. **EMPTY ≠ ABSENT.** No probe output may feed a verdict, a plan, or an
   accusation without its exit status. The `set +e; x=$(…); rc=$?; set -e`
   idiom at `clean.sh:45` is the house pattern; A1/C2/C3/C4 are the sites.
2. **One writer, atomic bless.** Unique part names (PID/nonce) or an
   exclusive lock, and finalize must be race-safe (A2).
3. **Pin the locale.** `export LC_ALL=C` at every entry point (A3).
4. **Verdict vocabulary is API.** Every token verify.sh can print (OK,
   REVIEW, FAIL, **WAIVED**) must be in every parser; dying-mid-print must
   be distinguishable from FAIL (C1).
5. **A scanner states its jurisdiction.** ts-health/clean must say what they
   can and cannot see for this container/topology (B1/B2/B3/B4/F12) instead
   of printing an unscoped CLEAN.
6. **The harness counts skips**, cross-checks each case's tail line against
   its exit status, and derives rosters from the tree (E1/E2/E3/E7).
